## How to use this repository

1. Open a problem folder and read its `README.md`.
2. Review the corresponding `.java` solution.
3. To run a judge-style solution, choose **Java** on the matching LeetCode problem and use its provided method signature.
4. For local execution, supply an appropriate test harness and inputs. Judge-style `Solution` classes are not standalone applications.
